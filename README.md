# MOBON Performance Marketing Proposal

GitHub Pages용 정적 웹 제안서입니다.

## 배포
1. 이 폴더 안의 `index.html`, `styles.css`, `script.js`, `assets`를 GitHub 저장소 최상위(root)에 업로드합니다.
2. GitHub 저장소 → Settings → Pages
3. Source: `Deploy from a branch`
4. Branch: `main`
5. Folder: `/(root)`
6. Save

최종 URL 형식:
`https://GITHUB-ID.github.io/REPOSITORY-NAME/`
